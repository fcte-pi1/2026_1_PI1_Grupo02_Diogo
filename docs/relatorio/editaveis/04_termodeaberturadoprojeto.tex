\section{Objetivos}
O objetivo principal deste projeto é desenvolver e gerenciar a construção de um robô Micromouse autônomo, capaz de mapear e resolver fisicamente labirintos de diferentes dimensões, integrado a uma aplicação web para armazenamento e exibição de dados de telemetria em tempo real, utilizando a gestão por Estrutura Analítica do Projeto (EAP).

Para a correta definição, seguem os objetivos detalhados sob a regra SMART:

\begin{description}
    \item [\textit{Specific} (específico):] Desenvolver um sistema robótico autônomo (máximo de 25 cm de comprimento ou largura) capaz de navegar em labirintos de dimensões 4x4, 8x8 e 16x16 sem pular, voar, escalar ou danificar a pista. O projeto engloba a criação de uma interface web conectada a um banco de dados (Modelo Entidade-Relacionamento) para exibir e armazenar em tempo real a telemetria da corrida: tipo de labirinto, trajeto por coordenadas (x,y), consumo de energia, velocidade média, tempo de conclusão e status de sucesso. Todo o projeto será versionado no GitHub seguindo padrões de repositório e controle de tarefas por \textit{issues}.    
    \item [\textit{Measurable} (mensurável):] O sucesso será atestado pela capacidade do robô em completar os três tamanhos de labirintos de forma totalmente autônoma, pelo armazenamento íntegro dos dados de "Desafio" e "Trajeto" no banco de dados e pela construção física da pista de testes 4x4 com chão preto e paredes brancas de 5 cm com topos vermelhos.
    \item [\textit{Agreed} (acordado):] O escopo e os requisitos técnicos deste projeto foram definidos em comum acordo entre os membros da equipe e estão plenamente alinhados com as diretrizes e competências técnicas exigidas pela disciplina de Projeto Integrador 1 (PI1). O plano de trabalho recebeu o aval do professor.
    \item [\textit{Realistic} (realista):] A execução do projeto fundamenta-se na utilização de componentes de baixo custo e alta disponibilidade no mercado nacional, tornando a construção financeiramente viável. A complexidade do algoritmo é compatível com o cronograma acadêmico e com o nível de conhecimento técnico da equipe, prevendo a confecção de um labirinto modular para testes preliminares antes da avaliação oficial.
    \item [\textit{Time Bound} (Limitado no tempo):]O desenvolvimento está estritamente vinculado ao calendário acadêmico do semestre letivo. O cronograma estabelece que a parte que vamos usar nos testes esteja pronto um pouco antes, garantindo que o protótipo esteja plenamente funcional para a bateria de testes oficiais no labirinto. A entrega final, incluindo o ratinho e a documentação técnica completa, ocorrerá impreterivelmente na data estipulada para a apresentação final da disciplina.
\end{description}

\section{Mercado-alvo}

O mercado-alvo deste projeto é composto por estudantes e profissionais da área acadêmica, incluindo professores e pesquisadores, além de instituições de ensino, que usufruem diretamente dos produtos e resultados gerados pelo desenvolvimento do micromouse e do sistema de monitoramento associado.
De forma mais específica, destacam-se:

\begin{itemize}

    \item Estudantes de engenharia e áreas tecnológicas (como Engenharia de Software, Elétrica, Computação e Mecatrônica), que utilizam o projeto como ferramenta prática de aprendizado.
    \item Instituições de ensino (universidades, faculdades e escolas técnicas), que podem adotar o micromouse como recurso didático.
    \item Professores e pesquisadores, que utilizam o projeto para experimentação e avaliação de algoritmos.    

\end{itemize}

\section{Justificativa}

O projeto do \textit{Micromouse} surgiu como uma oportunidade de 
desenvolver, na prática, um sistema robótico autônomo completo, 
integrando hardware, software embarcado e uma interface web de 
monitoramento. Para estudantes de engenharia, esse tipo de projeto 
é valioso porque exige a aplicação simultânea de conhecimentos de 
diferentes áreas, algo que dificilmente acontece em disciplinas 
isoladas. O desenvolvimento do sistema serve como ponto de encontro entre
as engenharias de Software, Eletrônica, Energia e Aeroespacial
presentes na FCTE.

Além disso, o \textit{Micromouse} pode ser utilizado como recurso 
didático por instituições de ensino, já que combina conceitos de 
algoritmos, eletrônica, controle e comunicação de dados em um único 
sistema tangível. Professores e pesquisadores também se beneficiam 
do projeto ao utilizá-lo para experimentação e avaliação de 
diferentes abordagens de navegação autônoma.

Portanto, o projeto se justifica por gerar um produto com aplicação 
direta no contexto acadêmico, desenvolvido inteiramente pela equipe 
sem o uso de soluções prontas, o que reforça o aprendizado 
interdisciplinar proposto pela disciplina de Projeto Integrador de 
Engenharia 1.
